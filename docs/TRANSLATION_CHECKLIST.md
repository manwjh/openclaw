# 翻译检查清单

在提交翻译前，请使用此清单检查你的工作。

## 基础检查

- [ ] 文件命名正确：`原文件名_cn.md`
- [ ] 文件位置正确：与英文原版在同一目录
- [ ] YAML front matter 完整且正确
- [ ] 文档结构完整：所有章节都已翻译
- [ ] 没有遗漏任何段落或内容

## 格式检查

- [ ] Markdown 格式正确（标题、列表、代码块等）
- [ ] 代码块语法高亮正确
- [ ] 表格格式正确
- [ ] 链接格式正确
- [ ] 图片引用正确

## 内容检查

- [ ] 技术术语使用术语表中的标准翻译
- [ ] 术语在整个文档中保持一致
- [ ] 代码示例、命令、配置保持原样（未翻译）
- [ ] 变量名、函数名、命令名保持原样
- [ ] 专有名词（产品名、服务名）保持英文

## 链接检查

- [ ] 内部链接指向正确（已翻译的指向中文版，未翻译的指向英文版）
- [ ] 外部链接保持原样
- [ ] GitHub 链接正确
- [ ] 所有链接都可以正常访问

## 质量检查

- [ ] 翻译准确，没有误解原文
- [ ] 中文表达自然流畅
- [ ] 符合中文表达习惯
- [ ] 没有明显的语法错误
- [ ] 标点符号使用正确（中文标点）

## 元数据检查

- [ ] `original_path` 指向正确的英文文档路径
- [ ] `translated_date` 填写正确
- [ ] `translator` 填写正确
- [ ] `sync_status` 填写当前同步的上游版本
- [ ] `last_sync_date` 填写最后同步日期

## 同步检查

- [ ] 已与上游最新版本同步
- [ ] 没有遗漏上游的更新
- [ ] 冲突已正确解决

## 提交前检查

- [ ] 已运行 `git status` 确认更改
- [ ] 提交信息格式正确：`docs: translate xxx to Chinese`
- [ ] 已测试本地预览（如果可能）
- [ ] 已阅读并理解 `TRANSLATION_WORKFLOW.md`

## 特殊检查项

### 代码块
- [ ] 所有代码块保持原样
- [ ] 代码中的注释未翻译
- [ ] 代码中的字符串未翻译

### 命令示例
- [ ] 命令保持原样
- [ ] 参数说明已翻译
- [ ] 输出示例保持原样（如果包含）

### 配置示例
- [ ] JSON/YAML 配置保持原样
- [ ] 配置项说明已翻译
- [ ] 注释（如果可翻译）已翻译

### 图片和图表
- [ ] 图片引用路径正确
- [ ] 图片中的文字（如果有）已翻译或说明
- [ ] Alt 文本已翻译

## 审查建议

提交前建议：
1. 自己通读一遍翻译
2. 对照英文原版检查
3. 使用 Markdown 预览工具检查格式
4. 如果可能，请他人审查

## 常见错误

避免以下常见错误：
- ❌ 翻译代码块中的内容
- ❌ 翻译命令和参数
- ❌ 翻译变量名和函数名
- ❌ 术语不一致
- ❌ 遗漏元数据
- ❌ 链接指向错误
- ❌ 格式错误
